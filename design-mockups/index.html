Three design directions for skimmynz.com

Each concept is a complete visual system — type, colour, layout and component language — shown across the four pages that matter: home, guide, top 100 and the haste calculator. Every mockup is real HTML/CSS (open the live file to inspect or resize).

00

Where it is now

for reference

Dark slate, purple accent, rounded cards, Inter throughout. Clean and readable — but visually it reads as a generic dashboard template with WoW art dropped in. Nothing about the type, colour or layout says "the rank 1 Shadow Priest wrote this."

01

Voidbound Codex

editorial · arcane grimoire

Treats the site as a printed tome. Cards disappear entirely — content sits on the page, separated by gold hairlines and generous whitespace. Cinzel display serif, roman numerals for chapters, drop caps, a sigil ring behind the hero. Data lives in a ledger table, not a widget.

Type Cinzel + Inter + JetBrains Mono Palette Void black · bone · amethyst · gold leaf Signature Hairlines, numerals, no cards

02

Parse HUD

telemetry · brutalist data

The site as an instrument panel. Zero border radius, clipped corners, a live status ticker, mono everywhere, acid-green numbers. The home page stops being a poster and becomes a deck of live modules. DoT breakpoints render as an actual tick timeline instead of a progress bar.

Type Rajdhani + JetBrains Mono + Inter Palette Near-black · insanity violet · acid lime · amber Signature Corner brackets, ticker, hazard stripes

03

Siege

cinematic · seasonal poster

Blockbuster treatment. Full-bleed raid art, 168px Anton headline bleeding off the grid, ember gradients and frosted glass. The seasonal theme becomes the whole identity — reskin it per tier. Top 100 leads with a podium; the calculator is a single glowing arc gauge.

Type Anton + Inter Palette Iron brown · ember orange · gold · cream Signature Full-bleed art, glass slabs, huge display type
